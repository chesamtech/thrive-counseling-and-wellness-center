# Mindful Path Counselling website

A responsive starter website for a new counselling business.

## Preview locally
1. Extract this ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser (or use the VS Code Live Server extension).

## Before publishing
1. Open `script.js`.
2. Replace `2547XXXXXXXX` with the counsellor's WhatsApp number, using country code and digits only (for example, Kenyan numbers start with `254`).
3. Confirm the actual business name, counsellor's credentials, service descriptions, location, and contact details.
4. Review the privacy and emergency-support wording with the counsellor. Do not add client testimonials or professional credentials unless they are genuine and approved.
5. The form sends the appointment request through WhatsApp; it does not store submissions on a server.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and styling
- `script.js` — mobile menu and WhatsApp appointment form
